MY GARAGE v3 — iPHONE HOME-SCREEN WEB APP

New: in-app maintenance reminders (date and mileage/hours), receipt/repair photos stored in IndexedDB, parts inventory with reorder levels and automatic stock usage from service logs. Full JSON export includes photo data. No push notifications or cloud sync.

Host all files at the SAME HTTPS origin as v2. Open in Safari and Share > Add to Home Screen. Export a backup before replacing the old app. Photos and records are stored locally on that device; clearing website data may erase them. Import a backup to restore.

Service intervals and part fitment require manual verification.
